# Wisesa POS untuk Android

Aplikasi POS dan Rekap Toko Wisesa. Unduh APK dari [rilis terbaru](https://github.com/idlanyor/tokowisesa-android-releases/releases/latest).

- Android 8 atau lebih baru.
- Printer target: Eppos EP-5802AI, Bluetooth, kertas 58 mm.
- Antarmuka Material 3, transaksi tunai/QRIS, riwayat, cetak struk dan rekap harian.
- Masuk memakai URL toko HTTPS, email dan password akun admin yang sama dengan web.

Instal file `.apk`, izinkan pemasangan dari sumber unduhan bila Android meminta, lalu buka Pengaturan aplikasi untuk masuk dengan akun admin toko. Pasangkan printer lewat Pengaturan Bluetooth Android, pilih di tab Printer dan lakukan tes cetak. Dukungan cetak perlu diverifikasi pada perangkat fisik.

Repository ini khusus distribusi APK. Source aplikasi dan workflow build disimpan privat. Arsip “Source code” otomatis dari GitHub hanya berisi dokumentasi repository rilis, bukan source aplikasi. Untuk memasang aplikasi, pilih file **Wisesa-POS-*.apk**.
